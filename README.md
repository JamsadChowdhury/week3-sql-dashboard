# Week 3 SQL Dashboard

## 📊 Overview
This project visualizes internship applicant data using Streamlit and SQLite.

## 🧩 Files
- `nextgen_db.ipynb` — Google Colab notebook used to create the database  
- `nextgen.db` — SQLite database containing all tables  
- `applicants_cleaned.csv`, `interns.csv`, `hackathon_scores.csv` — source data  
- `dashboard.py` — Streamlit dashboard script
- Screenshots are available in the screenshots/ folder.
